# CMFGEN / Knop / JFNK Vault

Working notebook for the `cmfgen_jfnk` development tree: CMFGEN running on
**non-monotonic velocity fields** for the SN 2024pba pipeline, and the
layered solver stack (Sobolev patch -> Knop formal solver -> Gauss-Seidel
field stabilization -> JFNK population solve) built to make that converge.

Open this folder as an Obsidian vault (`cmfgen_obsidian/` inside
`cmfgen_jfnk/`). Notes link to each other with double-bracket
wikilinks; source paths are given relative to the tree root in `code`.

## The one-paragraph version

A Type IIn ejecta has a velocity law `V(R)` that turns over: fast ejecta
hit slow dense CSM and the shell stalls, so
$\sigma = d\ln V/d\ln R - 1$ drops below $-1$. Stock CMFGEN assumes
$\sigma \ge -1$ inside its comoving-frame formal solver and produces
negative/NaN intensities there. This tree implements the Knop,
Hauschildt & Baron (2009) fix (sign-aware upwinding in frequency plus a
lagged coupling store `I_NEXT`), wraps it in a field-maturity controller
that holds the population solver on safe Lambda steps until the lagged
field is a fixed point, and - only near the end - replaces the
linearized population solve with a Jacobian-free Newton-Krylov step.
Everything is off by default; with the flags unset the binary is
upstream CMFGEN.

## Figures

Schematic figures in `attachments/` are generated by the Python +
matplotlib scripts in this folder: `make_figures.py` (the fig_*
schematics), `plot_iteration_cycle.py` (the great-iteration
flowchart), and `plot_knop_solver.py` (Sobolev vs Knop transfer).
Rerun them after any edit - they overwrite the PNGs in place:

```bash
cd cmfgen_obsidian && python3 make_figures.py
python3 plot_iteration_cycle.py && python3 plot_knop_solver.py
```

## Conventions used in these notes

- `flag` names in code font are VADAT keys unless stated otherwise.
- `#status/verified` `#status/partial` `#status/unverified` tags mark how
  well a claim is supported by runtime evidence (mirrors the repo's
  VERIFIED / SUPPORTED / UNVERIFIED / CONTRADICTED / BLOCKED policy).
- Plain ASCII throughout; `sigma`, `GAM`, `chi_hat` are written for the
  Fortran spellings $\sigma$, $\Gamma$, $\hat\chi$.
