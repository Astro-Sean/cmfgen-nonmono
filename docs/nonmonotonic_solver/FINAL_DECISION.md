The non-monotonic velocity solver implementation is usable within explicitly documented assumptions.

## Evidence

### Limitations
1. **Sobolev approximation**: Not a full non-monotonic RT solver; single-resonance local approximation
2. **Sigma clamp at -0.999**: Numerically stabilizing but physically approximate; creates flat σ plateau
3. **Monotonic regression test NOT RUN**: No monotonic input_hydro.dat available for X_v5
4. **Synthetic test cases NOT RUN**: Velocity reversal, plateau, discontinuity tests require synthetic inputs
5. **Flux conservation NOT quantitatively verified**: Only algebraic analysis performed
6. **Restart reproducibility NOT tested**
7. **3 RELATED changes unverified**: set_abund_clump.f, rd_sn_data.f, generate_full_matrix_v3.f

## Key Assumptions

1. The -0.999 sigma clamp is required for convergence (empirically confirmed, AGENTS.md)
2. The Dessart+2015 guard is the correct algebraic regularization for Sobolev GAM
3. The Sobolev approximation is valid for the X_v5 velocity field
4. The input_hydro.dat format is stable and correctly generated by the converter
5. The 3 RELATED changes (set_abund_clump, rd_sn_data, generate_full_matrix) preserve standard behavior

## Regimes Where Results Are Considered Unreliable

1. **Velocity plateaus (dV/dR ≈ 0)**: Sobolev approximation breaks down
2. **Sharp discontinuities**: Interpolation artifacts may dominate
3. **Multiple resonance points**: Not handled by single-resonance Sobolev
4. **σ << -1 (e.g., σ = -7.5)**: Clamp distorts physics significantly
5. **Very small grids (ND < 100)**: Boundary insertion may not leave enough interior points
